# Presentations

Slide decks, figures and videos made for meetings. Nothing in the pipeline or the dashboard reads from here.
Each folder is named `<date>-<occasion>` and holds the material and, where there is one, the code that built it.

| Folder | What it is |
| --- | --- |
| `2026-10-25-report-deck/` | HTML/PDF report deck; built by `code/build_deck.py` from `code/deck_figures.py` (reads `EXPERIMENTS/results/`) |
| `2026-11-03-group-meeting/` | Three-slide group-meeting deck |
| `2026-11-03-pipeline-video-v3/`, `2026-11-03-pipeline-video-v4/` | Narrated pipeline explainer videos (manim) |
| `2026-11-10-group-meeting/` | Group-meeting deck: calibration ladder and balance figures |
| `2026-11-13-supervisor-deck/` | Old vs new pipeline deck for the supervisor; scripts in `src/` and `src_v2/` |

Scripts that need the repository root find it themselves; run them from anywhere.
